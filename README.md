# Oi Peak Shaving Simulator

Cell site lithium battery peak-shaving savings calculator (Ontario case study) by [ORAN Infra Inc.](https://www.oraninfra.com/)

**Live:** https://loganhe-oi.github.io/peak-shaving-simulator/

Estimates annual electricity cost savings from using a telecom site's lithium battery bank for
time-of-use / ULO peak shaving, while always preserving the backup energy reserve needed for the
local utility's typical outage duration. Single static HTML file, no build step, no dependencies.
